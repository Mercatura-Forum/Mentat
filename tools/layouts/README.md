# Retired layouts

Each `*.most` here is the stable-type signature of a layout this contract once kept, frozen at the
commit named in the `.commit` file beside it. A layout is retired when a change alters the shape
of what the contract keeps; the change that retires it also carries the migration that carries it
forward (`src/Migration.mo`) and the gate that proves the path (`tools/stable_compat.sh`): the
retired signature upgrades to the migrating actor carrying that layout's migration
(`tools/migrating_actor.sh <dest> <layout>`), the migrating actor to the plain one, the plain one to
itself, and the retired signature is refused a direct upgrade to the plain actor.
